配置流程

1 申请 API 密钥

  • 申请地址：https://api.nsmao.net/register
  • 申请完成后，登录账号，点击个人中心，密钥管理，即可查看 API 密钥。

2 创建 JS 文件

  • 在博客目录的 source 文件夹下创建 static 目录，在 static 目录下创建 card-welcome.js 文件。

4. 复制对应的经度(lng)和纬度(lat)值
